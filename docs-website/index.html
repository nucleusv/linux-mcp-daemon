MCP Daemon

Linux MCP Daemon

A powerful, secure, and blazingly fast Model Context Protocol server for managing Linux filesystems.

📁 list_directory

Securely explore the filesystem. Powered by the Ephemeral Worker to prevent path traversal and ensure UID isolation.

{"path": "/var/log", "privileged": true}

💾 get_disk_space (df)

Query exact byte usage or inode saturation for any mount point. Includes advanced filtering to report raw counts or beautifully formatted human-readable output.

{"path": "/", "inodes": true, "human_readable": true}

📊 get_disk_usage (du)

Traverse massive directory trees efficiently with singleflight caching. Set thresholds, toggle apparent sizes, or calculate directories separately.

{"path": "/home", "threshold": 104857600, "separate_dirs": true}

Ephemeral Workers

To prevent security breaches, tools are never executed in the master process. Instead, we spawn a temporary worker using os/exec and syscall.Credential. This guarantees strict UID isolation and prevents runaway processes.

Singleflight Caching

Heavy tools like get_disk_usage are protected by the golang.org/x/sync/singleflight library and a 60s memory cache. This prevents the AI from saturating I/O when spamming requests.

Configuration

Manage connection limits and timeouts via configs/daemon.yaml, and control which users can execute "privileged": true requests via configs/mcp-sudo.yaml.
