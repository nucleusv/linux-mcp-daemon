## Upgrading from 0.4.0

Nothing has to change in your configs. One thing you will notice: every tool is now listed to every user.

- **Every tool is listed, granted or not.** In 0.4.0 a `docker/*` tool, and `daemon/reload-config`, appeared in `tools/list` only for a user whose grant allowed it. Now all of them are listed for everyone, and a call the user's grant does not allow fails with an error that names what is missing - `user testuser is not authorized to run docker/exec: ... needs allowed: true in its grant in mcp-sudo.yaml` - before anything reaches the Docker socket. A wrong call no longer looks like a typo (`no read target ...`), and `linuxctl` completion and `get mcp-api tools` show the same surface to every user. The four Docker resource templates were already listed to everyone; the tools now match them. Grants are unchanged: what a user may *do* is still decided by `mcp-sudo.yaml`. See [mcp-sudo.yaml](https://nucleusv.github.io/linux-mcp-daemon/v0.4.1/configuration/mcp-sudo/).
- **Tests:** `tests/test_linuxctl.sh` runs against any target - local k8s by default, a VPS stand through environment variables - and includes a docker section.
