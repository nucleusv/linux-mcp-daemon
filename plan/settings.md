# Settings and Configuration Plan

This document tracks the utilities and capabilities for managing system, network, and daemon settings in the MCP Daemon.

## MCP Daemon Configuration

- [ ] **mcpd-config** (`settings/update/daemon`): Read and update the `mcp-sudo.yaml` and server configurations.

## System Configuration

- [ ] **hostnamectl**: Query or change the system hostname.
- [ ] **timedatectl**: Query or change system time and date settings.
- [ ] **localectl**: Query or change system locale and keyboard settings.

## Network Configuration

- [ ] **nmcli / nmtui**: NetworkManager command line tool to view or configure network connections.
- [ ] **resolvconf**: Manage DNS settings.
