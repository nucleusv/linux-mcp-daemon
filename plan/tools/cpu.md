# CPU Group Implementation Plan

This document tracks the standard Linux CPU utilities and their implementation status in the MCP Daemon.

## CPU Topology

- [x] **lscpu / /proc/cpuinfo** (`cpu/list`): Display information about the CPU architecture.
- [ ] **mpstat**: Report processors related statistics.
- [ ] **sar**: Collect, report, or save system activity information.
- [ ] **pidstat**: Report statistics for Linux tasks (processes).
